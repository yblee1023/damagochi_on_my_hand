# Pocket Creature

다마고치풍 몬스터 육성 게임. 의존성 없는 단일 HTML 파일 하나로 동작한다.

- 흑백 LCD, 픽셀 아트, 3×5 비트맵 폰트
- 조작은 기기의 A / B / C 세 버튼뿐
- 오리지널 1996년판과 같은 일 단위 타임라인 — 성체까지 6일
- 진행 상황은 `localStorage`에 저장되고, 창을 닫아도 시간은 계속 흐른다 (최대 3일치)

## 실행

`index.html`을 브라우저로 열면 된다. GitHub Pages로 올리면 어느 기기에서든 접속해서 플레이할 수 있다.

> Settings → Pages → Source를 `main` 브랜치 루트로 지정하면
> `https://<사용자명>.github.io/<저장소명>/` 에서 열린다.

## 조작

| 버튼 | 기본 화면 | 하위 페이지 | 미니게임 |
|---|---|---|---|
| A | 아이콘 이전 | 항목 이전 | 왼쪽 |
| B | 실행 | 확인 / 닫기 | 그만두기 |
| C | 아이콘 다음 | 항목 다음 | 오른쪽 |

키보드 ← → Enter 로도 같은 조작이 된다.

아이콘은 FEED(밥·간식) / PLAY / SWEEP / BATH / LIGHT / MED / STATUS / DEX 8종이다.

돌봄이 필요해지면 **화면 전체가 반전되며 깜빡이고** 해당 아이콘도 함께 깜빡인다. 소리 대신 쓰는 호출 신호라 음소거 상태나 백그라운드 탭에서도 알아볼 수 있다.

## 시간

오리지널 1996년판의 타임라인을 따른다.

| 단계 | 시점 |
|---|---|
| 부화 | 5분 |
| 아기 → 어린이 | 65분 |
| 어린이 → 청소년 | 3일 |
| 청소년 → 성체 | 6일 |

단계마다 정해진 취침 시각이 있고, 자는 동안에는 배가 고파지지도 심심해지지도 않는다. 밤이 되면 화면이 깜빡이며 불을 꺼달라고 부르고, 아침 8시에는 저절로 깬다.

| 단계 | 취침 |
|---|---|
| 아기·어린이 | 21시 ~ 8시 |
| 청소년·성체 | 22시 ~ 8시 |

> 오리지널은 20~9시(어린이 기준)지만 그대로 쓰면 깨어 있는 시간이 직장인의 근무 시간과 정확히 겹쳐서, 저녁에만 접속하는 사람은 밥을 한 번도 먹이지 못하고 굶겨 죽이게 된다. 기기를 주머니에 넣고 다니던 1996년과 달리 브라우저 탭은 들고 다닐 수 없어서 한 시간 늦추고 8시 기상으로 바꿨다.

## 케어 실수와 죽음

케어 실수는 방치한 시간에 비례해 쌓이지 않는다. **호출 한 건이 실수 하나**이고, 유예 20분 안에 응답하면 실수로 치지 않는다. 계속 무시하면 3시간마다 다시 부른다. 자리를 9시간 비워도 실수가 수십 개씩 쌓이지는 않는다는 뜻이다.

죽음은 방치가 곧바로 부르는 것이 아니라 질병을 거친다. 호출을 무시하면 체력이 깎이고, 체력이 낮아지면 병에 걸리며, 병을 오래 방치하면 죽는다. 완전히 손을 놓으면 약 1.5일 만에 죽는다.

## 성장과 진화

```
EGG → PIP → POKO → EMBER  → PYRON / CINDER / ASTRA
                 → RIPPLE → TIDEON / MURK  / ASTRA
```

- **EMBER / RIPPLE 분기** — 유년기 동안의 평균 애정도가 기준치를 넘으면 EMBER, 아니면 RIPPLE
- **성체 분기** — 케어 실수 횟수로 온전한 형태와 망가진 형태가 갈린다
- **ASTRA** — 실수 없이, 충분히 놀아주고, 청결·건강 평균까지 높을 때만 나오는 숨은 형태

애정을 채우는 길은 둘이다. 미니게임으로 놀아주거나, 간식을 주거나. 간식은 건강을 조금씩 깎기 때문에 같은 애정이라도 결과가 달라진다.

생활 패턴별 시뮬레이션 결과 (아침·점심·저녁 접속 빈도를 달리해 6일 육성):

| 플레이 방식 | 결과 | 케어 실수 |
|---|---|---|
| 자주 접속 + 많이 놀아줌 | ASTRA | 1 |
| 자주 접속 + 간식 위주 | TIDEON | 2 |
| 아침·점심·저녁 + 놀아줌 | PYRON | 3 |
| 아침·저녁 + 놀아줌, 목욕 안 시킴 | CINDER | 29 |
| 아침·저녁 + 아무것도 안 함 | MURK | 33 |
| 완전 방치 | 1.5일 뒤 사망 | — |

목욕을 거르면 청결이 0에 붙어 호출이 계속 울리고 실수가 빠르게 쌓인다. 실수 수십 개는 대부분 여기서 나온다.

## 개발 노트

밸런스 상수는 전부 파일 상단 `CFG` 객체에 모여 있다. 감소율, 발병 확률, 성장 단계 시각(`stages`), 진화 판정 기준(`evo`)을 여기서 조정한다.

주소 끝에 `#dev`를 붙이면 1분이 20ms로 흘러서, 6일짜리 전체 수명을 3분 만에 확인할 수 있다. 낮밤 판정은 실제 시각이 아니라 `S.clock` 가상 시계를 쓰기 때문에 dev 모드에서도 취침·기상이 정상적으로 돌아간다.

```
index.html#dev
```

스프라이트는 16×16 문자 배열이고, `HOLES`에 적힌 문자만 배경색으로 뚫린다(눈·입). 나머지는 전부 검게 채워진다. 흑백이라 실루엣이 곧 정체성이므로, 새 몬스터를 추가할 때는 몸통 윤곽 자체를 다르게 잡고 날개·지느러미는 반드시 몸통에 붙여야 한다. 떨어져 있으면 부속물이 아니라 옆에 떠 있는 얼룩으로 읽힌다.

세이브 키는 `pocket-creature.save.v2`, 도감은 `pocket-creature.dex.v2`다. 저장 구조를 바꿀 때는 버전을 올린다.
