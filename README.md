# Pocket Creature

다마고치풍 몬스터 육성 게임. 의존성 없는 단일 HTML 파일 하나로 동작한다.

- 흑백 LCD, 픽셀 아트, 3×5 비트맵 폰트
- 조작은 기기의 A / B / C 세 버튼뿐
- 오리지널 1996년판의 내부 수치를 그대로 — 성체까지 약 2.5일
- 진행 상황은 `localStorage`에 저장되고, 창을 닫아도 시간은 계속 흐른다 (최대 3일치)

## 실행

`index.html`을 브라우저로 열면 된다. GitHub Pages로 올리면 어느 기기에서든 접속해서 플레이할 수 있다.

> Settings → Pages → Source를 `main` 브랜치 루트로 지정하면
> `https://<사용자명>.github.io/<저장소명>/` 에서 열린다.

## 조작

| 버튼 | 기본 화면 | 하위 페이지 | 미니게임 |
|---|---|---|---|
| A | 아이콘 이전 | 항목 이전 | 왼쪽 |
| B | 실행 | 확인 / 닫기 | 그만두기 |
| C | 아이콘 다음 | 항목 다음 | 오른쪽 |

키보드 ← → Enter 로도 같은 조작이 된다.

아이콘은 FEED(밥·간식) / PLAY / SWEEP / BATH / LIGHT / MED / STATUS / DEX 8종이다.

돌봄이 필요해지면 **화면 전체가 반전되며 깜빡이고** 해당 아이콘도 함께 깜빡인다. 소리 대신 쓰는 호출 신호라 음소거 상태나 백그라운드 탭에서도 알아볼 수 있다.

## 시간

오리지널 1996년판의 타임라인을 따른다.

| 단계 | 체류 시간 |
|---|---|
| 알 | 5분 |
| 아기 | 65분 |
| 어린이 | 1380분 (23시간) |
| 청소년 | 2220분 (37시간) |

성체까지 약 2.5일. 위키 요약본에는 "3일에 청소년, 6일에 성체"라고 적혀 있지만, ROM에서 추출된 P1/P2 내부 수치는 위와 같고 케어 실수 허용치(0~2회)와도 앞뒤가 맞는다.

단계마다 정해진 취침 시각이 있고, 자는 동안에는 배가 고파지지도 심심해지지도 않는다. 밤이 되면 화면이 깜빡이며 불을 꺼달라고 부르고, 아침 8시에는 저절로 깬다.

| 단계 | 취침 | 배고픔 | 애정 |
|---|---|---|---|
| 아기 | — | 3분/칸 | 4분/칸 |
| 어린이 | 20시 ~ 9시 | 50분/칸 | 60분/칸 |
| 청소년 | 21시 ~ 9시 | 75분/칸 | 85분/칸 |
| 성체 | 22시 ~ 9시 | 86분/칸 | 95분/칸 |

하트는 4칸이고 밥 한 번이 한 칸을 채운다. 어린이는 3시간 20분이면 배가 텅 비므로 하루에 여러 번 앉아서 먹여야 한다. 알에서 깬 첫 한 시간은 3분마다 한 칸씩 빠져서 거의 붙어 있어야 한다. 이 수치는 P1/P2의 하트 손실 주기를 그대로 가져온 것이다.

## 케어 실수와 죽음

케어 실수는 방치한 시간에 비례해 쌓이지 않는다. **호출 한 건이 실수 하나**이고, 유예 30분 안에 응답하면 실수로 치지 않는다. 계속 무시하면 6시간마다 다시 센다.

> 오리지널은 재호출이 훨씬 잦지만 그 난이도는 기기를 주머니에 넣고 다니는 것을 전제로 한다. 브라우저 탭은 들고 다닐 수 없어서, 감소 속도는 원조를 따르되 재호출 간격만 늘렸다. 자리를 비운 대가는 실수 횟수가 아니라 체력과 질병으로 받게 하려는 것이다.

죽음은 방치가 곧바로 부르는 것이 아니라 질병을 거친다. 호출을 무시하면 체력이 깎이고, 체력이 낮아지면 병에 걸리며, 병을 오래 방치하면 죽는다.

| 방치 | 케어 실수 | 상태 |
|---|---|---|
| 3시간 | 1 | 멀쩡 |
| 6시간 | 3 | 체력 88, 발병 |
| 9시간 | 7 | 체력 68, 발병 |
| 12시간 | 11 | 체력 53 |
| 24시간 | — | 18시간째 사망 |

반나절만 자리를 비워도 그 단계의 온전한 성체는 물 건너간다. 오리지널이 기기를 주머니에 넣고 다니는 것을 전제로 설계된 난이도이기 때문이고, 여기서는 그 난이도를 그대로 뒀다.

## 성장과 진화

```
EGG → PIP → POKO → EMBER  → PYRON / CINDER / ASTRA
                 → RIPPLE → TIDEON / MURK  / ASTRA
```

- **EMBER / RIPPLE 분기** — 유년기 동안의 평균 애정도가 기준치를 넘으면 EMBER, 아니면 RIPPLE
- **성체 분기** — 케어 실수 횟수로 온전한 형태와 망가진 형태가 갈린다
- **ASTRA** — 실수 없이, 충분히 놀아주고, 청결·건강 평균까지 높을 때만 나오는 숨은 형태

분기는 **단계별 돌봄 품질**로 정해진다. 청소년 형태는 어린이 단계의 케어 실수로, 성체 형태는 청소년 단계의 케어 실수로 갈린다. 각 단계에서 0~2회면 양호, 3회 이상이면 불량이다.

| 어린이 단계 | 청소년 단계 | 결과 |
|---|---|---|
| 0~2회 | 0~2회 | EMBER → PYRON |
| 0~2회 | 3회 이상 | EMBER → CINDER |
| 3회 이상 | 0~2회 | RIPPLE → TIDEON |
| 3회 이상 | 3회 이상 | RIPPLE → MURK |

RIPPLE은 출발이 부실했다는 뜻이지 실패가 아니다. 청소년 단계에서 만회하면 TIDEON이 된다. ASTRA는 두 단계 모두 실수 0회에 충분히 놀아주고 건강·청결까지 유지했을 때만 나온다.

생활 패턴별 시뮬레이션 결과 (접속 시간대와 빈도를 달리해 6일 육성):

| 플레이 방식 | 결과 |
|---|---|
| 하루 세 번 이상 + 게임으로 놀아줌 | ASTRA |
| 초반 부실, 이후 만회 | PYRON / TIDEON |
| 아침·저녁만 | MURK |
| 간식으로만 행복을 채움 | 비만으로 4~7일 뒤 사망 |
| 초반에 열심, 이후 방치 | 4.3일 뒤 사망 |
| 완전 방치 | 0.8일 뒤 사망 |

온전한 성체를 보려면 하루에 세 번은 들여다봐야 한다. 간식 연타는 가장 빠른 자살 경로다.

## 개발 노트

밸런스 상수는 전부 파일 상단 `CFG` 객체에 모여 있다. 감소율, 발병 확률, 성장 단계 시각(`stages`), 진화 판정 기준(`evo`)을 여기서 조정한다.

주소 끝에 `#dev`를 붙이면 1분이 20ms로 흘러서, 6일짜리 전체 수명을 3분 만에 확인할 수 있다. 낮밤 판정은 실제 시각이 아니라 `S.clock` 가상 시계를 쓰기 때문에 dev 모드에서도 취침·기상이 정상적으로 돌아간다.

```
index.html#dev
```

## 체중

간식은 **배부름과 무관하게 언제든 먹는다.** 오리지널도 그렇다. 간식을 막는 것은 제한이 아니라 체중이다.

| 행동 | 효과 |
|---|---|
| 밥 | 배고픔 한 칸, 체중 +1 (배부르면 거절) |
| 간식 | 행복 한 칸, 체중 +2 (절대 거절 안 함) |
| 미니게임 | 행복 한 칸, 체중 −1 (이기든 지든) |

기본 체중은 아기 5, 어린이 10, 청소년 20, 성체 30이고 그 아래로는 내려가지 않는다. 최대 99. 기본 체중을 넘길수록 병에 걸리기 쉬워지고, 40 넘게 초과하면 체력이 직접 깎인다. 간식만으로 행복을 채우면 살이 쪄서 병을 달고 살다 일찍 죽는다.

**행복은 간식이 아니라 게임으로 채우는 것이 요령이다.** 게임은 행복을 올리면서 체중을 깎는 유일한 수단이다. 아기는 체중이 늘지 않아 간식을 줘도 된다.

기운(REST)은 오리지널에 없는 스탯이라 역할을 좁혀뒀다. 밤에 불을 꺼서 재웠는지만 반영하고, 미니게임은 기운을 소모하지 않는다. 놀이에 기운 비용을 붙였더니 많이 놀아줄수록 기운이 말라 더는 놀아줄 수 없게 되고, 그래서 애정이 0으로 떨어지는 역방향 피드백이 생겼기 때문이다. 기운이 바닥나면 체력 회복이 멈추고 병에 걸리기 쉬워진다.

스프라이트는 16×16 문자 배열이고, `HOLES`에 적힌 문자만 배경색으로 뚫린다(눈·입). 나머지는 전부 검게 채워진다. 흑백이라 실루엣이 곧 정체성이므로, 새 몬스터를 추가할 때는 몸통 윤곽 자체를 다르게 잡고 날개·지느러미는 반드시 몸통에 붙여야 한다. 떨어져 있으면 부속물이 아니라 옆에 떠 있는 얼룩으로 읽힌다.

세이브 키는 `pocket-creature.save.v2`, 도감은 `pocket-creature.dex.v2`다. 저장 구조를 바꿀 때는 버전을 올린다.
